### 2. What will the following code return?

```py
from transformers import pipeline

ner = pipeline("ner", aggregation_strategy="simple")
ner("My name is Sylvain and I work at Hugging Face in Brooklyn.")
```

**Choices**
- It will return classification scores for this sentence, with labels "positive" or "negative".
  - Explanation: This is incorrect — this would be a <code>sentiment-analysis</code> pipeline.
- It will return a generated text completing this sentence.
  - Explanation: This is incorrect — it would be a <code>text-generation</code> pipeline.
- It will return the words representing persons, organizations or locations.
  - Explanation: Furthermore, with <code>aggregation_strategy=&quot;simple&quot;</code>, it will group together the words belonging to the same entity, like "Hugging Face".

### 5. What does "transfer learning" mean?

**Choices**
- Transferring the knowledge of a pretrained model to a new model by training it on the same dataset.
  - Explanation: No, that would be two versions of the same model.
- Transferring the knowledge of a pretrained model to a new model by initializing the second model with the first model's weights.
  - Explanation: When the second model is trained on a new task, it *transfers* the knowledge of the first model.
- Transferring the knowledge of a pretrained model to a new model by building the second model with the same architecture as the first model.
  - Explanation: The architecture is just the way the model is built; there is no knowledge shared or transferred in this case.

### 7. Select the sentence that best describes the terms "model", "architecture", and "weights".

**Choices**
- If a model is a building, its architecture is the blueprint and the weights are the people living inside.
  - Explanation: Following this metaphor, the weights would be the bricks and other materials used to construct the building.
- An architecture is a map to build a model and its weights are the cities represented on the map.
  - Explanation: The problem with this metaphor is that a map usually represents one existing reality (there is only one city in France named Paris). For a given architecture, multiple weights are possible.
- An architecture is a succession of mathematical functions to build a model and its weights are those functions parameters.
  - Explanation: The same set of mathematical functions (architecture) can be used to build different models by using different parameters (weights).


### 8. Which of these types of models would you use for completing prompts with generated text?

**Choices**
- An encoder model
  - Explanation: An encoder model generates a representation of the whole sentence that is better suited for tasks like classification.
- A decoder model
  - Explanation: Decoder models are perfectly suited for text generation from a prompt.
- A sequence-to-sequence model
  - Explanation: Sequence-to-sequence models are better suited for tasks where you want to generate sentences in relation to the input sentences, not a given prompt.

### 9. Which of those types of models would you use for summarizing texts?

**Choices**
- An encoder model
  - Explanation: An encoder model generates a representation of the whole sentence that is better suited for tasks like classification.
- A decoder model
  - Explanation: Decoder models are good for generating output text (like summaries), but they don't have the ability to exploit a context like the whole text to summarize.
- A sequence-to-sequence model
  - Explanation: Sequence-to-sequence models are perfectly suited for a summarization task.

### 10. Which of these types of models would you use for classifying text inputs according to certain labels?

**Choices**
- An encoder model
  - Explanation: An encoder model generates a representation of the whole sentence which is perfectly suited for a task like classification.
- A decoder model
  - Explanation: Decoder models are good for generating output texts, not extracting a label out of a sentence.
- A sequence-to-sequence model
  - Explanation: Sequence-to-sequence models are better suited for tasks where you want to generate text based on an input sentence, not a label.

### 11. What possible source can the bias observed in a model have?

**Choices**
- The model is a fine-tuned version of a pretrained model and it picked up its bias from it.
  - Explanation: When applying Transfer Learning, the bias in the pretrained model used persists in the fine-tuned model.
- The data the model was trained on is biased.
  - Explanation: This is the most obvious source of bias, but not the only one.
- The metric the model was optimizing for is biased.
  - Explanation: A less obvious source of bias is the way the model is trained. Your model will blindly optimize for whatever metric you chose, without any second thoughts.
